# MnM Maps v0.1.0

First public release of the standalone map overlay for Monsters & Memories.

- 33 community wiki map views across 26 zones, including Wyrmsbane Tomb, Tel Ekir, Grain Cellar, Blind Midden's ground floor, Sunken Resort, and other dungeons.
- Manual map selection, mouse wheel zoom, drag to pan, and Fit.
- Personal pins, notes, and remembered views per drawing.
- Adjustable opacity, always on top mode, tray controls, and mouse passthrough.
- Ctrl+Shift+M to show/hide; Ctrl+Shift+L to lock/unlock mouse passthrough.
- Cached maps for offline viewing and import of your own images.

## Install

Download **MnMMaps-win-x64.zip**, extract it, and run **MnMMaps.exe**. For a Start Menu shortcut, run **install.bat** from the extracted folder. Alternatively, download **MnMMaps.exe** on its own. The .NET runtime is included.

Use the game in windowed or borderless mode. [Installation, updates, backups, and troubleshooting](https://github.com/goofysillyguy/mnm-maps/blob/main/docs/INSTALLATION.md) are documented in the repository and ZIP.

An existing local copy uses the same `%LOCALAPPDATA%\MnMMaps` data folder. Quit that copy before opening this release; your pins and settings remain available.

## Known limits

Map selection is manual; there is no live position or zone tracking. Night Harbor Sewers, Glinting Hollow, and The Hidden Grotto have no verified wiki map in this catalog. Some drawings contain several floors on a single image. The initial release does not have a single-instance guard.

Build and packaged checks cover rendering, cache reads, pin coordinates, zoom, centering, persistence, and image import. Native shortcuts, tray behavior, mixed DPI displays, and mouse passthrough still need interactive checks on each desktop setup.

The app is unsigned. **SHA256SUMS.txt** contains hashes for the EXE and ZIP. Original map images are downloaded when selected and retain their own credits and licensing; no wiki images are bundled in these release files.

MnM Maps does not access the game process, game files, screen contents, or game network traffic. It is an unofficial fan companion, without developer endorsement.
