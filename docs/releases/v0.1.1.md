# MnM Maps v0.1.1

This release includes the new parchment-map and turquoise-compass application icon and a map-only lock mode in the downloadable Windows executable.

- Uses the new icon for the EXE in File Explorer, the running window/taskbar, and the notification-area tray.
- Embeds icon sizes from 16 to 256 pixels for Windows display scaling.
- Uses native Windows bitmap data for the smaller icon sizes to keep taskbar and tray rendering compatible.
- Includes the icon resource inside the standalone EXE; no separate image or icon file is required.
- Lock hides the window controls and borders, leaving only the map and personal pins with mouse passthrough. Ctrl+Shift+L or **Unlock mouse and show** in the tray menu restores the controls. Locking keeps the map at its current position and zoom.

The icon source commit did not replace the v0.1.0 release downloads. Download this version to get the updated executable.

## Download and update

Download **MnMMaps.exe** to run directly, or **MnMMaps-win-x64.zip** for the executable and optional installer. Quit any running copy of MnM Maps first, then replace your previous executable or run **install.bat** from the newly extracted ZIP. Your maps, settings, and pins remain in `%LOCALAPPDATA%\MnMMaps`.

If you pinned an older shortcut to the taskbar and it still shows the old icon after updating, unpin that shortcut, open the updated executable, and pin it again. A shortcut can also point to an older installed copy; updating the ZIP download alone does not replace that installation.

[Detailed installation and update instructions](https://github.com/goofysillyguy/mnm-maps/blob/main/docs/INSTALLATION.md). **SHA256SUMS.txt** lists the hashes of this release's EXE and ZIP.
