# MnM Maps 0.2.0 — MnMAtlas support

- Full live MnM Atlas page inside the overlay, with native page menus, maps, floors, search, markers, notes, and community tools.
- Persistent Atlas browser profile and remembered map view.
- Native support for site pop-ups, sign-in navigation, note imports, export save dialogs, and fullscreen.
- Atlas address field and navigation/search shortcuts, alongside the existing global show/hide and lock shortcuts.
- Map-only lock hides app and site controls while retaining the view, markers, and attribution.
- Wiki maps preserves existing image maps, cached downloads, local imports, and personal pins.
- Microsoft Edge WebView2 Runtime is required for Atlas. Windows 10 version 2004 or newer, x64, is required by this edition.

Atlas notes use the overlay's own browser profile. To bring in notes from your usual browser, use Atlas's Export there and Import inside the overlay. Updates preserve the saved-data folder and existing Wiki maps pins.

Quit the older overlay from its tray menu before running the new EXE or installer. The ZIP includes setup instructions, the Atlas guide, and third party license notices. Atlas's site and identity provider control the availability of their online features.
