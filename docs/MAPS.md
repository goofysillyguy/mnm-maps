Several dungeon maps draw their levels on one image. Zoom and pan to the appropriate section. Pins are saved per drawing. Selecting a different rendition of the same zone starts a separate pin list because the layout and image coordinates differ.

## Known gaps

No wiki map has been verified for **Night Harbor Sewers**, **Glinting Hollow**, or **The Hidden Grotto** in this catalog. Blind Midden currently has only its ground-floor drawing. Screenshots and placeholder graphics are excluded from the selection.

If you have another drawing, use **Import image** to add it locally, or [open an issue](https://github.com/goofysillyguy/mnm-maps/issues) with a link to its public source page. Include the zone, floor or version, and known author. A useful map can be incomplete, but its limitations should be identified.

## Sources

Catalog entries and original file-page links are in [`src/MnMMaps.App/Data/maps.json`](../src/MnMMaps.App/Data/maps.json). Newly discovered entries record their source and check date. **Wiki source** in the app opens the original file page; see [NOTICE.md](../NOTICE.md) for source credits and licensing boundaries.

The catalog updater preserves existing IDs and gives additional drawings distinct IDs. Program updates therefore retain pins on their original image rather than moving them to a new drawing.
